# 개인 프로젝트

### 주제: 파이썬을 활용한 RAW 드라이브 파일 복구 프로그램 개발

* 제작 기간 : 25.10.01 ~ 26.01.16

* 제작 인원 : 1명

* 선정 배경
    > 프로젝트를 진행하던가 작업을 하다보면 USB, SD카드는 필수로 필요하다. 하지만 간혹 디스크가 RAW드라이브로 바뀌면서 포맷을 해야 다시 사용할 수 있는 경우가 생긴다.<br>실제로 현미경으로 관찰한 자료를 열어야 하는데 SD카드가 RAW상태가 되면서 포맷하지 않으면 열 수 없는 상황이 생긴적이 있다.<br>이를 해결하고자 인터넷에 검색을 하니 chkdsk명령어를 사용하면 된다고 나왔다. 하지만 해당 SD카드는 그 명령어를 사용할 수 없었다.<br>이에 복구 프로그램을 설치하여 복구를 하려고 하였으나 가격이 만만치 않게 비쌌다<br>그래서 복구에 필요한 프로그램을 직접 개발하여 누구든 저렴하게 사용할 수 있게 하고자 주제를 선정하게 되었다.
